# 费用配置与汇率转换设计

> 日期：2026-03-24
> 状态：设计确认

## 1. 概述

本次设计包含四个紧密关联的功能模块：

1. **全局人民币→港币转换**：所有金额字段统一人民币输入、港币存储与显示
2. **固定费用月配置**：月初配置房租、水电、管工工资等固定费用，新增记录时自动代入
3. **费用汇算规则**：部分字段新增计算公式、新增字段、修改简称
4. **汇率历史记录**：记录每月汇率变更，可在数据备份模块中查询

## 2. 全局人民币→港币转换

### 2.1 规则

- 录入员在明细表中**新增记录**时输入人民币值
- 后端保存时自动转换：`存储值(HKD) = 输入值(RMB) / 汇率`
- 汇率来源：`formula_constants` 表中 `name = 'exchange_rate'` 的当月生效值
- 数据库直接存港币，明细表、汇总表、三工汇总、Excel 导出统一显示港币

**汇率方向示例：** 若 `exchange_rate = 0.88`（1港币 = 0.88人民币），录入员输入 `100 人民币`，则存储值 = `100 / 0.88 = 113.64 港币`。

### 2.2 编辑记录

编辑已有记录时，对话框直接显示数据库中的**港币值**，用户在港币基础上修改。编辑提交的值不再经过汇率转换，直接存储。

### 2.3 受影响字段

所有金额类字段（费用、产值、工资等）均参与转换。通过在 `modules/balance/config.js` 中为字段增加 `currency: true` 标记来识别需要转换的字段。

**需要转换（`currency: true`）的字段：**
- **共享费用**：员工工资、管工工资、房租、水电费、工具投资、设备、装修、杂费、运费、社保、税收
- **各部门独有金额字段**（物料、维修、工资类等全部金额费用）
- **总产值**

**不做转换的字段（无 `currency` 标记）：**
- 人数类（整数）：员工人数、管工人数、杂工人数等
- 比率类（百分比）：开机率、结余%、总工资占产值%等
- 台数类：总台数、开机台数
- 工时类：员工工时、开机时间、总工时
- 文本类：备注

### 2.4 前端交互

- 新增对话框：输入框无变化，用户输入人民币数值，保存后表格显示港币值
- 编辑对话框：显示港币值，用户直接修改港币值
- 无需实时预览换算结果

### 2.5 汇率缺失处理

当系统中没有找到当月或之前任何月份的汇率配置时，保存操作应**拒绝并报错**：「请先在系统设置中配置当月汇率（exchange_rate）」。不使用默认值，避免错误数据入库。

### 2.6 历史数据

现有数据均为测试数据，无需迁移处理。

## 3. 固定费用月配置

### 3.1 功能定位

每月初由录入员配置当月固定费用参数（房租总额、水电费、管工奖金等），系统在新增每日记录时自动计算并代入对应字段。

### 3.2 入口位置

各部门明细表筛选栏中，新增「⚙ 固定费用配置」按钮（录入员和统计组均可见），点击打开配置弹窗。

### 3.3 配置项清单

| # | 项目 | 英文标识 | 类型 | 适用部门 | 代入公式 |
|---|------|---------|------|---------|---------|
| 1 | 总台数 | `total_machines` | 半永久 | 啤机 | 直接代入 |
| 2 | 当月上班天数 | `work_days` | 每月 | 三部门各自设置（值相同，但各部门独立配置窗口） | 供其他公式引用 |
| 3 | 房租 | `rent` | 每月 | 啤机/印喷/装配 | `总房租 / 上班天数 / 汇率` |
| 4 | 管工底薪 | `gw_base_salary` | 半永久 | 啤机/印喷/装配 | 与奖金合并：`(底薪 + 奖金) / 上班天数 / 汇率` |
| 5 | 管工奖金 | `gw_bonus` | 每月 | 啤机/印喷/装配 | 与底薪合并：`(底薪 + 奖金) / 上班天数 / 汇率` |
| 6 | 水电（啤机） | `utility_unit` | 每月 | 啤机 | `每台水电单价 × 当日开机台数 / 汇率` |
| 7 | 水电（印喷/装配） | `utility_total` | 每月 | 印喷/装配 | `总水电费 / 上班天数 / 汇率` |

**类型说明：**
- **半永久**：设置一次后长期生效，直到手动更新。`effective_month` 存储为 `'0000-00'`（哨兵值），查询时取 `effective_month <= 当月` 的最新值即可自动命中。
- **每月**：每月初必须录入当月值。

### 3.4 弹窗 UI 设计

参考现有系统设置中的常量配置弹窗，包含以下区域：

**快捷标签区：** 点击标签自动填充项目名称和英文标识

```
[总台数] [房租] [管工底薪] [管工奖金] [水电单价/总水电费] [上班天数]
```

**通用输入行：** 项目名称（中文）、英文标识、生效月份（半永久可留空）、值（人民币）、保存按钮

**管工工资专用行：** 紫色底色区分，包含：管工底薪（半永久，留空沿用上次）、管工奖金（每月）、生效月份、当月上班天数、保存按钮。下方显示代入公式说明。

**已配置列表：** 表格展示当前部门所有配置项，包含项目名称、英文标识、类型（半永久/每月）、生效月份、值、代入公式、删除操作。

**说明区：** 底部注意事项，说明半永久/每月的区别、金额单位、汇率来源等。

UI 预览文件：`public/preview-fixed-expense.html`

### 3.5 存储方案

复用现有 `formula_constants` 表，通过 `module` 字段区分：

| module 值 | 用途 |
|----------|------|
| `balance` | 现有全局常量（汇率、税点） |
| `balance_fixed_beer` | 啤机部固定费用 |
| `balance_fixed_print` | 印喷部固定费用 |
| `balance_fixed_assembly` | 装配部固定费用 |

不需要新建表。每个部门各自存储 `work_days`，虽然值通常相同，但保持独立以支持各部门录入员分别操作。

### 3.6 代入逻辑（方案 A：写入时计算）

录入员新增一条记录时，后端自动：
1. 查询该部门当月生效的所有固定费用配置
2. 查询当月汇率
3. 按公式计算出各字段的港币日均值
4. 将计算值写入记录对应字段

已有记录不受后续配置修改影响。如需更新，使用「重算历史」功能（需扩展，见 7.5 节）。

### 3.7 权限

固定费用配置功能位于部门模块中，直接复用该模块的权限体系：
- **录入员**：有部门模块权限即可打开配置弹窗、录入月度配置值；明细表中固定费用字段**显示但不可编辑**
- **统计组**：可配置，同时可以在明细表中**手动覆盖**单条记录上的固定费用字段值

### 3.8 固定费用配置 API

复用现有常量 API（`/api/settings/constants`），通过 `module` 参数区分部门。但需修改该接口的权限中间件：当 `module` 为 `balance_fixed_*` 时，放行录入员（原接口 `requireStats` 限制统计组专用）。管工工资专用行在前端组合底薪和奖金两条常量一起保存。

## 4. 费用汇算规则

### 4.1 现有字段改动

| 部门 | 字段 | 改动内容 |
|------|------|---------|
| 啤机 | 开机台数 | 从手工输入改为**计算字段**：`开机时间(run_hours) / 24`，`input` 改 `false`，`calc` 改 `true`，类型可能产生小数 |

| 装配 | 计划总工资含×1.13 | 新增时输入人民币 → 后端 `× 1.13 / 汇率`。注意：1.13 是固定的社保系数，**不是**税点常量，不从 `formula_constants` 读取 |
| 装配 | 实际总工资 | 新增时输入人民币 → `/ 汇率` |

| 部门 | 字段名 | 英文标识 | 位置 | 类型 | 参与结余 |
|------|--------|---------|------|------|---------|
| 啤机 | 人均产值 | `per_capita_output` | 不含税产值后面 | 计算字段（`总产值 / 员工人数`） | 否（展示字段） |

## 5. 汇率历史记录

### 5.1 新建表

```sql
CREATE TABLE exchange_rate_history (
  id SERIAL PRIMARY KEY,
  effective_month VARCHAR(7) NOT NULL,     -- 生效月份，如 '2026-03'
  old_value NUMERIC(10,4),                 -- 修改前的值（首次录入为 NULL）
  new_value NUMERIC(10,4) NOT NULL,        -- 修改后的值
  changed_by VARCHAR(100) NOT NULL,        -- 操作人用户名
  changed_at TIMESTAMPTZ DEFAULT NOW()     -- 修改时间
);
```

### 5.2 记录触发

在 `POST /api/settings/constants` 接口中，当保存的常量 `name = 'exchange_rate'` 时：
1. 查询该月份当前值作为 `old_value`（首次录入则为 NULL）
2. 插入一条历史记录（`effective_month`, `old_value`, `new_value`, `changed_by`, `changed_at`）

### 5.3 查询界面

放在数据备份模块中，表格按月份展示：

| 列 | 说明 |
|----|------|
| 月份 | 生效月份 |
| 当前汇率 | 该月最新的汇率值，紫色加粗显示 |
| 历史修改记录 | 该月所有变更，格式：`2026/3/25  0.90 → 0.88（张统计）` |

## 6. 数据流总览

```
录入员操作流程：
  月初 → 打开「固定费用配置」→ 输入当月房租、奖金、水电、上班天数
  每天 → 新增记录 → 输入产值、人数、各项费用（人民币）
                   → 后端自动（按以下顺序执行）：
                      1. 查询当月汇率（缺失则报错拒绝保存）
                      2. 计算字段先行：开机台数 = 开机时间/24，总工时 = 人数×工时
                      3. 读取固定费用配置 → 计算代入：
                         - 总台数：直接代入
                         - 房租：总房租 / 上班天数 / 汇率
                         - 管工工资：(底薪+奖金) / 上班天数 / 汇率
                         - 水电（啤机）：单价 × 开机台数 / 汇率
                         - 水电（印喷/装配）：总水电费 / 上班天数 / 汇率
                      4. 所有金额字段（currency: true）/ 汇率 → 存港币
                      5. 计算结余等衍生字段
                   → 返回记录（表格显示港币）

  编辑记录 → 对话框显示港币值 → 用户直接修改 → 提交值直接存储（不再转换）

统计组查看：
  明细表 → 港币值
  汇总表 → 港币汇总
  三工汇总 → 港币汇总
  Excel 导出 → 港币值
```

## 7. 技术要点

### 7.1 后端转换层

在 `routes/records.js` 的 POST 处理中，增加统一的转换步骤：
1. 从 `formula_constants` 查询当月汇率，缺失则返回 400 错误
2. 计算依赖字段：开机台数（啤机）、总工时（印喷）
3. 读取固定费用配置，按公式计算并填入对应字段
4. 遍历提交的字段，对标记 `currency: true` 的金额字段执行 `值 / 汇率`
5. 固定费用字段（录入员提交时忽略前端传值），使用配置计算值
6. 统计组提交的固定费用覆盖值，同样 `/ 汇率` 后存储
7. 计算结余等衍生字段

PUT（编辑）处理中，提交值直接存储，不做汇率转换。统计组覆盖固定费用字段时，输入的港币值直接存储。

### 7.2 计算顺序

单条记录保存时的计算存在依赖关系，必须按以下顺序执行：

```
第一步：基础计算字段（不依赖汇率和配置）
  → 开机台数 = 开机时间 / 24（啤机）
  → 总工时 = 员工人数 × 员工工时（印喷）

第二步：固定费用代入（依赖第一步和汇率）
  → 总台数：直接代入
  → 房租 = 总房租 / 上班天数 / 汇率
  → 管工工资 = (底薪 + 奖金) / 上班天数 / 汇率
  → 水电（啤机）= 单价 × 开机台数(第一步结果) / 汇率
  → 水电（印喷/装配）= 总水电费 / 上班天数 / 汇率

第三步：汇率转换（所有 currency: true 的用户输入字段）
  → 各金额字段 = 输入值 / 汇率

第四步：衍生计算字段（依赖第二、三步结果）
  → 人均产值 = 总产值(已转港币) / 员工人数（啤机）
  → 不含税产值 = 总产值 / (1 + 税点)
  → 结余 = 总产值 - SUM(所有费用)
  → 结余% = 结余 / 总产值
  → 其他比率字段
```

### 7.3 字段可编辑性控制

前端需根据用户角色动态设置固定费用字段的可编辑状态：
- 录入员（`entry`）：固定费用字段 `readonly`，紫色底色标识（`--summary-bg: #F3E5F5`）
- 统计组（`stats`）：固定费用字段可编辑

在 `config.js` 中为固定费用字段增加 `fixedExpense: true` 标记，前端据此判断是否只读。

### 7.4 啤机水电特殊处理

啤机部水电公式依赖当日记录中的「开机台数」字段，而开机台数本身是计算字段（`开机时间 / 24`）。因此必须先完成第一步计算（得到开机台数），再执行第二步固定费用代入（水电 = 单价 × 开机台数 / 汇率）。

### 7.5 重算历史功能扩展

现有的「重算历史」功能（`routes/settings.js` 中的 recalculate 接口）仅重算公式计算字段。需要扩展以支持：
1. 重新读取固定费用配置并代入
2. 重新执行 RMB→HKD 转换（基于记录日期对应月份的汇率）
3. 按照 7.2 节定义的计算顺序完整重算

这样当月中修改了固定费用配置或汇率时，可以通过重算更新已有记录。

### 7.6 特殊公式说明

装配部「计划总工资含×1.13」的 1.13 是**固定社保系数**，直接在代码中硬编码为 `1.13`，不从 `formula_constants` 表的税点（`tax_rate`）读取。两者是不同的概念。
